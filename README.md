# 英语背诵助手

面向初中生日常英语背诵作业的轻量 PWA。单词、短语、句子和课文都可以按同一套简单流程学习：**先回忆 → 听读校正 → 如实标记 → 重点再背**。

## 已实现功能

- 粘贴中英文内容，自动拆分为逐条背诵卡片
- 上传 TXT、CSV、TSV、JSON 文件
- 拍照识别中英文教材或作业纸（OCR 结果可在保存前校对）
- “不认识 / 模糊 / 已掌握”三档状态管理
- 不认识和模糊内容优先进入重点复习
- 英语自动朗读，可选语音、速度和重复次数
- 看提示背英文、跟读、连续朗读三种使用方式
- 单条内容修改、删除；单份作业导出
- 全部作业与进度备份、恢复
- 手机与电脑自适应；核心功能离线可用；可安装到桌面
- 示例内容取自项目需求中的 `9.3` 背诵作业图片

## 最简单的数据格式

每行一条，中英文之间使用竖线或 Tab：

```text
我对科学感兴趣 | I am interested in science.
我性格外向 | I am outgoing.
为上课做好准备 | get ready for class
```

也支持直接粘贴“中文 英文”形式，以及中文、英文分成相邻两行的内容。

CSV 可使用 `中文,英文` 或 `prompt,answer` 作为表头。JSON 支持 `prompt/answer`、`chinese/english`、`zh/en` 等常见字段。

## 本地运行

项目不依赖框架或构建工具。为启用 PWA 和离线缓存，请通过本地 HTTP 服务打开：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 检查与测试

```bash
npm test
npm run check
```

## 数据与隐私

背诵作业和学习状态保存在当前浏览器的 `localStorage` 中，不会自动上传到服务器。图片 OCR 也在浏览器内执行；首次使用需要联网下载 Tesseract.js 及中英文识别数据。换设备或清理浏览器前，请在设置中“导出全部数据”。
