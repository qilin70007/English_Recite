# 英语背诵助手

面向初中生日常英语背诵作业的轻量 PWA。单词、短语、句子和课文都可以按同一套简单流程学习：**先回忆 → 听读校正 → 如实标记 → 重点再背**。

## 已实现功能

- 使用【中文】/【英文】标签明确导入；核对区逐条大卡片、中英文独立大输入框、长内容自动增高，支持上移/下移/新增/删除/撤销删除
- 上传 DOCX、TXT、CSV、TSV、JSON 文件；Word 正文、列表及常见中英表格提取后进入核对区
- 拍照识别中英文教材或作业纸（OCR 结果可在保存前校对）
- “不认识 / 模糊 / 已掌握”三档状态管理
- “重点复习”只选不认识和模糊内容，保留作业本中的先后顺序
- 开始背诵按导入顺序显示；手动调整过词条顺序时沿用调整后的顺序，掌握状态和复习时间不会让内容重新排序
- 每份作业支持“整篇查看”，完整显示英文、中文和备注，保留长课文换行；从背诵页查看后可返回原词条
- 背诵卡优先显示在首屏，数字进度居中显示在卡片顶部状态行；整篇查看、英文开关和单条朗读集中在范围筛选上方，设置在底部导航
- 英语自动朗读，可选语音、速度和重复次数
- “播放整份”按当前筛选清单逐条先读中文提示、再读英文，自动切换词条，末尾回到第一条循环，直到停止
- 支持整份作业或逐条上传 MP3；单条朗读优先播放该词条的 MP3，没有时自动使用 TTS
- 中英文分段使用对应语言朗读；中文独立采用正常语速和自然音高
- 普通话声音可选、可试听；优先使用本机已安装的语音，避免误选粤语
- “始终显示英文”开关：默认关闭，每次切换词条先看提示；打开后英文保持显示，偏好会自动保存
- 独立“MP3”按钮循环播放导入的整份录音，切换词条、标记状态和查看答案不会打断；停止后可从原位置继续
- 背诵页可选择某一作业本或所有作业本，并筛选“不认识 / 模糊 / 不认识＋模糊”
- 作业本支持上移、下移、改名及整本逐条校对
- 单条内容修改、删除；单份作业导出
- 未掌握内容导出真正的 Word `.docx`，可勾选一本、多本或全部作业本，按“不认识 / 模糊 / 未标记”筛选，保留原顺序、中文提示、英文和备注
- ZIP 完整备份、恢复：包含全部作业、进度、顺序、MP3 原文件和音频对应位置；兼容旧 JSON
- 手机与电脑自适应；核心功能离线可用；可安装到桌面
- 原生 Android APK：内置网页资源、原生中英文 TTS 和系统文件选择器
- 示例内容取自项目需求中的 `9.3` 背诵作业图片

## v1.9.1：紧凑默写版与原生息屏清单播放

- 中文默写版只保留作业本名称、序号、中文提示和书写位置，不打印不认识／模糊等状态，也不打印筛选范围。常见单词和短语使用 16 磅字、同行填写横线，A4 每页约 15 条；长句和课文自然换行并增加书写空间，不缩小或截断内容。
- 安卓“播放整份”把当前筛选清单交给原生播放器，中文、答题等待、英文／词条 MP3、重复次数、自动切卡与循环均不依赖网页计时器。息屏和切到其他应用后继续播放，返回时同步当前卡片；通知栏可以停止播放。整本 MP3 仍保持独立播放。
- 原生播放仅使用本次筛选的词条，并保留词条 MP3 优先级、导入顺序和语音选择。为后台播放准备的音频放在临时缓存中，停止后清理；原作业、音频关联、学习状态和备份结构不变。
- 安卓验证使用独立测试语音引擎，通过真实 TextToSpeech 音频完成回调推进队列；锁屏期间主动暂停 WebView 计时器，检查跨多轮朗读、答题等待、筛选清单中的 MP3／TTS、亮屏同步和通知栏停止。测试引擎只在测试 APK 内，用户安装包不包含它。

## v1.9.0：重难点、定期复习、默写与听题回忆

- 卡片右上角星标独立记录重难点，适用于单词、短语、句子和课文。首次出现“不认识／模糊”自动加入，以后标成已掌握也保留；人工取消后不再自动加回，可手动重新加入。旧数据中的不认识／模糊自动补标，旧已掌握内容不推测历史。
- 首页“开启定期复习”可选择参加的作业本，保存后显示“今天复习 · N 条”，包含到期和逾期内容。新词条首次自测后次日复习；到期时仍掌握，后续间隔依次为 3、7、14、30 天，之后保持 30 天。不认识／模糊重置为次日；同一天重复标记不会连跳周期，提前练习不会推迟原到期日。
- 只有自测后点击状态才更新计划；翻卡、听读、看答案不算完成。勾选加入计划的旧已学内容今天即可复习；未开始内容不会提前计入。可暂停某本计划，并选择新作业本是否自动加入。
- 范围筛选支持“只看重难点”“今天到期”，可与作业本、掌握状态组合。当前一轮仍保持条目顺序，标记后下一轮点“重新开始”重新筛选；今日到期数量会立即更新。日期按设备本地日历计算，应用内显示到期内容，不额外推送每日通知。
- Word 导出新增“中文默写版”，保留中文提示和按内容长度安排的书写空白，不输出英文答案或可能透露答案的备注。缺少中文提示时先提示补充；默认仍为中英对照版，支持多作业本，采用 A4。
- 设置中的清单播放方式分为“跟读”“听题回忆”。听题回忆按“中文 → 等待 → 英文 → 下一条”循环，等待可选 3、5、10、20、30 秒，默认 5 秒；等待及读题时隐藏英文与备注。此时英文常显开关暂不可用，停止后恢复原偏好。没有中文提示直接读英文，单条 MP3 在答案阶段仍优先播放；整份 MP3 维持原录音。
- 翻页取消旧等待并从新词条开始；停止、退出、编辑、打开设置取消剩余回调。完整 ZIP 备份保存重难点、人工取消记录、复习阶段／日期、作业本加入状态和播放偏好，恢复后保持一致。
- Android 使用用户启动的媒体前台服务和原生计时维持息屏播放，通知中提供“停止播放”，切回页面保持同一清单。停止或清除任务后释放播放服务。实现依据：[Android 媒体前台服务](https://developer.android.com/develop/background-work/services/fgs/service-types#media)、[WebView 生命周期](https://developer.android.com/reference/android/webkit/WebView#onPause())。网页版本的锁屏行为仍由浏览器管理。

推荐使用：当天先跟读、再隐藏英文自测；第二天点“今天复习”；周末选“所有作业本＋只看重难点”；车上选薄弱清单并启用听题回忆；需要默写时导出中文默写版。

## Android APK

仓库的 `Build Android APK` 工作流会在每次更新后自动生成可直接安装的调试版 APK：

1. 打开仓库的 **Actions** 页面。
2. 进入最新的 **Build Android APK** 运行记录。
3. 在页面底部下载 `English_Recite-Android`，解压后得到带版本号的 APK。

APK 使用 Android 原生文字转语音功能，上传文件和照片也会调用手机系统选择器。支持 Android 7.0（API 24）及以上系统。调试版已自动签名，适合在自己的手机上直接安装测试；系统首次安装时可能需要允许浏览器或文件管理器“安装未知应用”。

从 v1.0.1 起，APK 会发现并依次尝试 Google、讯飞及手机中的其他系统朗读引擎，并可在设置中测试朗读或打开系统朗读设置。v1.1.0 增加本机 MP3、整本编辑、作业排序和跨作业筛选。由于 GitHub Actions 每次生成的调试签名可能不同，如果新版提示无法覆盖安装，请先在旧版设置中导出备份，再卸载旧版并安装新版；JSON 备份不包含 MP3 文件。

v1.2.0 优先采用手机已选的系统朗读引擎，并按语言选择已安装的声音，普通话排除粤语候选。中文使用 1.0×，设置中的慢速仅作用于英文及 MP3。可在设置中先试听“名称。名词。今天我们一起学习英语。”再保存，查看文字与实际读音是否对应。语音自然程度取决于设备的语音包，不能仅靠应用保证每个多音字或专有名词都正确；需要固定读音时可用已上传的 MP3。Android 声音选择依据：[TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)、[Voice](https://developer.android.com/reference/android/speech/tts/Voice)。

v1.4.0 只在“作业本”页面提供新建入口。每张作业卡直接显示开始背诵、重点复习、整体编辑、导出 Word，以及上移、下移、导出 JSON、删除，无需打开“更多”菜单。首页和状态按钮统一使用居中 SVG 图标，背诵卡只保留提示、英文、备注和必要操作。

v1.5.0 可在首页当前作业、每张作业本卡片或背诵页点击“整篇查看”，一次查看该作业的全部内容（包含已掌握、未标记等所有条目）。英文完整展开，中文与备注紧随其后，长课文可滚动阅读，保留原换行。从背诵页打开后点击“返回背诵”或关闭，不改变当前位置，也不打断整份 MP3；从首页或作业本打开后，可直接从头开始背诵。学习队列现在按保存的词条顺序生成，不再按状态或最近复习时间排序；原有作业无需重新导入，手动调整的顺序继续生效。跨作业本和状态筛选同样保留原有相对顺序。

v1.6.0 将背诵卡移到上方主视野，删除背诵页顶部返回键。卡片下方依次是“整篇查看”和数字进度（如 1 / 15），右侧为“始终显示英文”；再下方是状态、翻页及连续播放。“作业范围 / 背诵类别 / 重新开始”位于页面最下方，从这里重新开始会回到上方卡片。长课文翻到下一条时也会把新卡片带回视野。应用标题居中，手机设置移到底部“背诵 / 作业本 / 设置”导航，电脑设置位于侧栏底部。打开设置不会重置当前词条。

v1.6.1 将数字进度移入单词卡顶部，在状态和编辑按钮之间居中显示。卡片下方先保留状态判断、翻页和连续播放，再显示“整篇查看 / 始终显示英文 / 朗读”，紧接“作业范围 / 背诵类别”区域。英文开关靠左与整篇查看相邻，单条朗读位于开关右侧；窄屏显示较长的“播放 MP3”按钮时可自然换行，开关和朗读仍保持相邻。

v1.7.0 的连续朗读按“中文提示一次 → 英文（按设置重复）→ 下一条”进行。中文使用普通话声音和正常语速，英文继续沿用语速及重复设置；本条有 MP3 时先读中文提示，再播放本条 MP3。整份 MP3 仍按原录音连续播放。停止、翻页或重启朗读会取消旧的播放回调和等待任务，避免意外跳条。

作业本现在可以选择 `.docx` 文件，离线提取正文、列表和表格文字后进入核对区，保存前可增删、排序和修改中英文。支持分散在多个文字片段中的【中文】/【英文】标签、手动换行、常见中英表格表头和序号列；不导入页眉、页脚、修订中已删除的文字。无标签的表格单元格内部换行会合并为空格，长课文需要保留换行时推荐使用【英文】标签。图片型 Word 请改用拍照识别；`.doc` 请先用 Word/WPS 另存为 `.docx`。为保证手机响应，单文件上限 32 MB、解压后的正文上限 8 MB。压缩 DOCX 需要支持 `DecompressionStream("deflate-raw")` 的浏览器内核；旧设备会提示更新 Android System WebView 或浏览器。结构依据：[WordprocessingML](https://learn.microsoft.com/en-us/office/open-xml/word/structure-of-a-wordprocessingml-document)、[Compression Standard](https://compression.spec.whatwg.org/)。

v1.8.0 将原来的播放入口拆成两个独立按钮：

- **MP3**：循环播放所选作业本导入的整份录音，不按词条状态裁剪。点击“停止MP3”暂停，点击“继续MP3”从原位置继续。筛选“模糊”等类别时仍可使用；跨多个作业本时按钮置灰，请先选择一个作业本。
- **播放整份**：从当前词条开始，只朗读本轮筛选清单，中文提示一次、英文按设置重复，有词条 MP3 时沿用词条 MP3。最后一条完成后回到清单第一条继续循环；点击“停止整份”结束。例如作业本有 20 条、当前只选中 5 条模糊内容，就只循环这 5 条，不会自动播放整本录音。清单只有一条时同样循环；筛选无结果时不会播放旧清单。

在范围或类别下拉框改选后，可直接点击“播放整份”，无需额外点击“重新开始”。播放中手动翻页或标记状态会切换到下一条继续读；本轮清单的成员和顺序保持不变，改选筛选条件或“重新开始”时重建。两种播放方式互斥，从 MP3 切到清单朗读会保留录音位置。退出背诵、打开设置或编辑内容时会停止对应播放，避免后台声音重叠。

背诵页的“始终显示英文”默认关闭，打开后当前条和后续条目都显示英文；关闭后恢复点击查看答案。设置会随完整备份一起保存。清单自动播放期间英文保持显示，更改英文开关不会打断播放。

“作业本 → 未掌握内容导出 Word”可勾选多本并提供全选、清空选择，默认选择不认识和模糊，可额外勾选未标记。从单本卡片的“导出 Word”进入会先选中该本，也可再勾选其他作业本。所选内容合并为一个标准 OOXML DOCX，按作业本和词条现有顺序排列，可在 Word 或 WPS 中继续编辑、打印。中英文按段落上下排列，避免长课文挤在表格中。

“设置 → 导出全部数据”现在生成一个 ZIP，恢复时直接选择 ZIP，无需解压。备份内 `backup.json` 记录原音频名称、原存储键、作业本/词条编号及顺序，并将文件放在独立的 `audio/00001.mp3` 等路径，重名音频不会互相覆盖。网页上传无法取得可跨设备使用的手机原绝对路径，因此同时备份音频本身，恢复不依赖该路径。若原音频已不在本机，导出和恢复都会明确提示缺失数量，并保留名称和关联。

旧 JSON 可以重新连接当前设备中具有原编号的音频，但无法从不存在的文件路径重建 MP3。从 v1.2.0 或更早版本升级且需要卸载时，除了导出旧 JSON，还应保留原始 MP3。v1.3.0 起的 ZIP 可一起迁移音频。

## 最简单的数据格式

推荐每条另起一行，用明确的标签区分。标签不会进入卡片或朗读：

```text
【中文】名称｜【英文】name
【中文】我对科学感兴趣｜【英文】I am interested in science.
【中文】为上课做好准备｜【英文】get ready for class
【英文】Hello.
```

【中文】后面是可选提示，【英文】后面是要背的实际内容。课文可在【英文】后写多行，下一个【中文】或【英文】标签开始新条目。标签格式优先于“按空行分段”。同一份输入请不要混用标签与未标注内容。

旧版“中文 | 英文”、直接粘贴“中文 英文”、中文与英文相邻两行的格式仍可使用。上传或粘贴后先点“下一步：核对内容”，在预览里校正对应关系，再确认保存；缺少英文的条目会明确提示补充。

CSV 可使用 `中文,英文` 或 `prompt,answer` 作为表头。JSON 支持 `prompt/answer`、`chinese/english`、`zh/en` 等常见字段。

## 本地运行

项目不依赖框架或构建工具。为启用 PWA 和离线缓存，请通过本地 HTTP 服务打开：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 检查与测试

```bash
npm test
npm run check
```

交互回归测试（使用模拟语音桥接检查请求语言、语速和声音选择，不能替代手机实听）：

```bash
npm ci
npx playwright install --with-deps chromium
npm run test:ui
```

Android 构建前自动运行手机宽度布局、整篇长课文显示与返回位置、导入/手动顺序、预览增删排序与自动增高、Word 筛选导出、音频备份清空后恢复、恢复写入失败回滚、MP3 连续播放、语音和进度检查，并保存截图。ZIP 采用标准 STORE 格式和 CRC32 校验，按 Blob 分段读写，音频无需重复压缩；Android 按 64 KB 分片接收文件，在后台写入系统选择的位置。恢复会先校验文件，再用新编号暂存音频，全部成功后才替换当前作业；失败会清理暂存音频并保留原数据。

## 数据与隐私

背诵作业和学习状态保存在当前浏览器的 `localStorage` 中，MP3 保存在本机 `IndexedDB`，都不会自动上传到服务器。图片 OCR 也在浏览器内执行；首次使用需要联网下载 Tesseract.js 及中英文识别数据。换设备或清理浏览器前，请在设置中“导出全部数据”，确认 ZIP 已保存到应用之外的位置。
