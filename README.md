# 英语背诵助手

面向初中生日常英语背诵作业的轻量 PWA。单词、短语、句子和课文都可以按同一套简单流程学习：**先回忆 → 听读校正 → 如实标记 → 重点再背**。

## 已实现功能

- 使用【中文】/【英文】标签明确导入；先核对预览，可直接修正中英文后保存
- 上传 TXT、CSV、TSV、JSON 文件
- 拍照识别中英文教材或作业纸（OCR 结果可在保存前校对）
- “不认识 / 模糊 / 已掌握”三档状态管理
- 不认识和模糊内容优先进入重点复习
- 英语自动朗读，可选语音、速度和重复次数
- 支持整份作业或逐条上传 MP3；有 MP3 时优先播放，没有时自动使用 TTS
- 中英文分段使用对应语言朗读；中文独立采用正常语速和自然音高
- 普通话声音可选、可试听；优先使用本机已安装的语音，避免误选粤语
- 看提示背英文、跟读、连续朗读三种使用方式
- 背诵页可选择某一作业本或所有作业本，并筛选“不认识 / 模糊 / 不认识＋模糊”
- 作业本支持上移、下移、改名及整本逐条校对
- 单条内容修改、删除；单份作业导出
- 全部作业与进度备份、恢复
- 手机与电脑自适应；核心功能离线可用；可安装到桌面
- 原生 Android APK：内置网页资源、原生中英文 TTS 和系统文件选择器
- 示例内容取自项目需求中的 `9.3` 背诵作业图片

## Android APK

仓库的 `Build Android APK` 工作流会在每次更新后自动生成可直接安装的调试版 APK：

1. 打开仓库的 **Actions** 页面。
2. 进入最新的 **Build Android APK** 运行记录。
3. 在页面底部下载 `English_Recite-Android`，解压后得到带版本号的 APK。

APK 使用 Android 原生文字转语音功能，上传文件和照片也会调用手机系统选择器。支持 Android 7.0（API 24）及以上系统。调试版已自动签名，适合在自己的手机上直接安装测试；系统首次安装时可能需要允许浏览器或文件管理器“安装未知应用”。

从 v1.0.1 起，APK 会发现并依次尝试 Google、讯飞及手机中的其他系统朗读引擎，并可在设置中测试朗读或打开系统朗读设置。v1.1.0 增加本机 MP3、整本编辑、作业排序和跨作业筛选。由于 GitHub Actions 每次生成的调试签名可能不同，如果新版提示无法覆盖安装，请先在旧版设置中导出备份，再卸载旧版并安装新版；JSON 备份不包含 MP3 文件。

v1.2.0 优先采用手机已选的系统朗读引擎，并按语言选择已安装的声音，普通话排除粤语候选。中文使用 1.0×，设置中的慢速仅作用于英文及 MP3。可在设置中先试听“名称。名词。今天我们一起学习英语。”再保存，查看文字与实际读音是否对应。语音自然程度取决于设备的语音包，不能仅靠应用保证每个多音字或专有名词都正确；需要固定读音时可用已上传的 MP3。Android 声音选择依据：[TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)、[Voice](https://developer.android.com/reference/android/speech/tts/Voice)。

手机作业本页面保留“重点复习 / 开始背诵 / 整体编辑”，上移、下移、导出与删除在“更多”中；“＋ 新建”始终显示文字。朗读时再次点击右上角“停止”即可结束。中文提示旁有独立的“听中文”。

## 最简单的数据格式

推荐每条另起一行，用明确的标签区分。标签不会进入卡片或朗读：

```text
【中文】名称｜【英文】name
【中文】我对科学感兴趣｜【英文】I am interested in science.
【中文】为上课做好准备｜【英文】get ready for class
【英文】Hello.
```

【中文】后面是可选提示，【英文】后面是要背的实际内容。课文可在【英文】后写多行，下一个【中文】或【英文】标签开始新条目。标签格式优先于“按空行分段”。同一份输入请不要混用标签与未标注内容。

旧版“中文 | 英文”、直接粘贴“中文 英文”、中文与英文相邻两行的格式仍可使用。上传或粘贴后先点“下一步：核对内容”，在预览里校正对应关系，再确认保存；缺少英文的条目会明确提示补充。

CSV 可使用 `中文,英文` 或 `prompt,answer` 作为表头。JSON 支持 `prompt/answer`、`chinese/english`、`zh/en` 等常见字段。

## 本地运行

项目不依赖框架或构建工具。为启用 PWA 和离线缓存，请通过本地 HTTP 服务打开：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 检查与测试

```bash
npm test
npm run check
```

交互回归测试（使用模拟语音桥接检查请求语言、语速和声音选择，不能替代手机实听）：

```bash
npm ci
npx playwright install --with-deps chromium
npm run test:ui
```

Android 构建前自动运行手机宽度布局、标签预览纠错、MP3 优先、状态防重复点击、筛选、语音分段、排序与改名的浏览器检查，并保存截图。

## 数据与隐私

背诵作业和学习状态保存在当前浏览器的 `localStorage` 中，MP3 保存在本机 `IndexedDB`，都不会自动上传到服务器。图片 OCR 也在浏览器内执行；首次使用需要联网下载 Tesseract.js 及中英文识别数据。换设备或清理浏览器前，请在设置中“导出全部数据”，并另外保留原始 MP3 文件。
